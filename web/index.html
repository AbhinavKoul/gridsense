How to read this · where the data comes from
Forecast peak load (default map)
Each area's highest hourly load over the next 7 days. Darker means a bigger peak. This is what GridSense routes against.
Routing lines
Wind that the grid would otherwise switch off (dispatch-down), booked for the biggest forecast peaks. Each line runs from a wind area to a peak area. Thicker lines carry more energy. Hover a line for the MWh, or see the table "Where the routed wind comes from".
Wind + solar share
The share of an area's electricity met by wind and solar, matched hour by hour. Hydro and bioenergy aren't counted. EirGrid publishes generation for the whole grid, not per county. So every area on the same grid draws the same hourly mix, and before routing all ROI areas show nearly the same number (for example 32.9% over 3 months). That's correct: wind is pooled nationally. Small differences come only from when each area uses power. Switch to "With GridSense routing" to see the peak areas pull ahead.
Local generation ÷ use
Renewables generated in an area divided by what it uses. Above 1× means the area exports wind (for example Kerry, Donegal, Leitrim). These are the sources the routing draws from.
Today's grid / With GridSense routing
The same 12 months of real demand and weather, without and with forecast-led routing.
Measured real data
EirGrid Smart Grid Dashboard, 15-minute data for ROI and NI, Oct 2025 – Oct 2026: demand, wind, solar, CO₂ intensity and wind forecast. CSO MEC02: data centres use 23.2% of ROI electricity. CSO MEC03: 2025 metered consumption by county and Dublin postal district. Census 2022 / NISRA populations.
Modelled estimate
Area load: system demand split by MEC03 consumption (ROI) or population (NI), with data-centre load sited at known clusters. County wind and solar capacity: approximate weights. Dispatch-down: wind forecast minus actual when the grid is ≥60% renewable. Half of that is treated as recoverable by scheduling transmission and storage against the forecast.
